# 2048 Game 🎮

A web-based implementation of the popular **2048 puzzle game**, built using **HTML**, **CSS**, and **JavaScript**.  
**Play it here:** https://dulsan002.github.io/2048-game/

---

## 📌 About the Game

**2048** is a single-player sliding tile puzzle game. The objective is to combine numbered tiles to create a tile with the number **2048**.

---

## 🕹️ How to Play

- Use your **arrow keys** (↑ ↓ ← →) to move the tiles.
- When two tiles with the same number touch, they **merge into one**.
- Your score increases with every merge.
- The game is over when no more moves are possible.

---

## 🚀 Features

- Classic 4x4 grid layout.
- Real-time score tracking.
- Responsive UI with color-coded tiles.
- Random tile generation.
- Game reset functionality.
- Keyboard controls (Arrow Keys).
- Loss condition detection.
